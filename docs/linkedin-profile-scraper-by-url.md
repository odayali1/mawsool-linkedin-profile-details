# Scrape a LinkedIn profile from a URL you already have

Send a LinkedIn profile URL that already opens. You get the role, about, location, education, certifications, and activity in one row.

Starting from $0.80 per 1,000 profiles.

Run it on Apify: https://apify.com/oday/mawsool-linkedin-profile-details. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

You already decided this profile is worth the full record.

## When to use a different Actor

You only need the current company and headline. Use Profile Freshness Check at $0.40 per 1,000, then scrape the rows you choose. The URL does not open. Use Fix Broken LinkedIn URLs first.
