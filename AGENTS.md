# LinkedIn Profile Scraper

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-profile-details` on Apify: https://apify.com/oday/mawsool-linkedin-profile-details
- Send a LinkedIn profile URL that already opens. You get the role, about, location, education, certifications, and activity in one row.
- Starting from $0.80 per 1,000 profiles.
- Use it when: You already decided this profile is worth the full record.
- Use something else when: You only need the current company and headline. Use Profile Freshness Check at $0.40 per 1,000, then scrape the rows you choose. The URL does not open. Use Fix Broken LinkedIn URLs first.
